# TundraUX V2.0.1

> **重要：v2 与 v1 的用户数据不兼容。**v1 的配置、个人资料、时钟数据和编辑器恢复草稿不会自动迁移。升级前请备份旧数据；v2 需要重新设置个人偏好。
>
> **Important: v2 is incompatible with v1 user data.** v1 settings, profiles, clock data, and editor recovery drafts are not migrated automatically. Back up the old data before upgrading; personal preferences must be set up again in v2.

## Main updates

- Launcher lists built-in and custom applications. Add, remove, and reorder shortcuts on Home; both pages share built-in app icons.
- The Editor can preview Word (`.docx`) and Excel (`.xlsx`) documents as read-only Markdown.
- Interface text is more concise, and the user and technical documentation and project screenshots have been updated.
- Fix window restoration after cross-app actions, accidental selection while scrolling the split application picker, missing launcher theme icons, and uneven progress gauge backgrounds.

See the [full changelog](https://github.com/peixuanthomas/TundraUX/blob/v2.0.1/docs/CHANGELOG.md#v201--2026-11-19) for changes since v2.0.0.

## Download and installation

| File | Platform |
| --- | --- |
| `TundraUX-v2.0.1-windows-x64.zip` | Windows x64 |
| `TundraUX-v2.0.1-macos-arm64.tar.gz` | macOS Apple Silicon (ARM64) |
| `TundraUX-v2.0.1-linux-x86_64.tar.gz` | Linux x86_64 portable package, built on Ubuntu 24.04 |

Each archive has a SHA-256 checksum file. Linux provides a portable package, without DEB or RPM packages.

```sh
tar -xzf TundraUX-v2.0.1-linux-x86_64.tar.gz
cd tundraux-2.0.1-linux-x86_64
./install-tux.sh
tux
```

Keep the extracted files together. The packages include English and Chinese resources and require a terminal of at least 108 columns by 20 rows. Linux is the primary target; Windows and macOS do not provide all Linux system-management features. The macOS package requires Apple Silicon and is neither developer-signed nor notarized by Apple.

## Build and release

The `Publish V2.0.1 release` GitHub Actions workflow builds, packages, and publishes all three platforms. The macOS application and Vim are built for Apple Silicon. The workflow checks versions, the release tag, the asset set, and SHA-256 checksums; it does not run the test suite.
