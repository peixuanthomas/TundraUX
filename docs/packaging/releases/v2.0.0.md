# TundraUX V2.0.0

> **重要：v2.0.0 与 v1 的用户数据不兼容。**v1 的配置、个人资料、时钟数据和编辑器恢复草稿不会自动迁移。升级前请备份旧数据；v2 需要重新设置个人偏好。
>
> **Important: v2.0.0 is incompatible with v1 user data.** v1 settings, profiles, clock data, and editor recovery drafts are not migrated automatically. Back up the old data before upgrading; personal preferences must be set up again in v2.

## Main updates

- Run applications in independent windows, minimize and restore them, and split the workspace into up to a 2×2 grid. Search the window selector or use Ctrl+W shortcuts to move between panes.
- A separate watchdog monitors Shell and application processes and can stop an unresponsive application.
- The interface has a more compact layout, updated Glacier Night styling, searchable selection dialogs, and improved focus, animation, scrollbars, and on-screen keyboard behavior.
- The workspace uses the current system user. Linux retains system user management.
- Command Line supports cycling suggestions with Right and accepting a completion with Tab. Source updates offer a selectable Git tree and show build output; Linux release updates show download progress and notes.
- Window communication, shared services, and interactive saves run in the background. Startup reuses language resources and records timing information.
- Configuration backups use transaction records. The project is now named TundraUX, and Linux portable builds include an installer for the `tux` command.

See the [full changelog](https://github.com/peixuanthomas/TundraUX/blob/v2.0.0/docs/CHANGELOG.md#v200--2026-11-17) for changes since v1.5.1.

## Download and installation

| File | Platform |
| --- | --- |
| `TundraUX-v2.0.0-windows-x64.zip` | Windows x64 |
| `TundraUX-v2.0.0-macos-arm64.tar.gz` | macOS Apple Silicon (ARM64) |
| `TundraUX-v2.0.0-linux-x86_64.tar.gz` | Linux x86_64 portable package, built on Ubuntu 24.04 |

Each archive has a SHA-256 checksum file. Linux provides a portable package, without DEB or RPM packages.

```sh
tar -xzf TundraUX-v2.0.0-linux-x86_64.tar.gz
cd tundraux-2.0.0-linux-x86_64
./install-tux.sh
tux
```

Keep the extracted files together. The packages include English and Chinese resources and require a terminal of at least 108 columns by 20 rows. Linux is the primary target; Windows and macOS do not provide all Linux system-management features. The macOS package requires Apple Silicon and is neither developer-signed nor notarized by Apple.

## Build and release

The `Publish V2.0.0 release` GitHub Actions workflow builds, packages, and publishes all three platforms. The macOS application and Vim are built for Apple Silicon. The workflow checks versions, the release tag, the asset set, and SHA-256 checksums; it does not run the test suite.
