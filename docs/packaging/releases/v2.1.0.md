# TundraUX V2.1.0

> **从 v1 升级前**，请备份配置、个人资料、时钟数据和编辑器恢复草稿。升级到 v2 后需要重新设置个人偏好。
>
> **Before upgrading from v1**, back up your settings, profiles, clock data, and editor recovery drafts. Set up your preferences again in v2.

## Main updates

- **Editor previews.** View PDF pages with page navigation, rotation, and zoom. Zoom and pan standalone images. Open more Word, Excel, and PowerPoint formats with their tables and embedded pictures.
- **Markdown reading.** Preview the current draft, including unsaved edits. You can read the text while local images, LaTeX formulas, and Mermaid diagrams render in the background.
- **File Explorer.** Search subfolders while keeping each result’s location. Create and extract ZIP, 7z, RAR, TAR, and TAR.GZ archives.
- **Workspace and Launcher.** Search apps by their localized names, add installed packages to Launcher, and share copied text between windows. Click the title for the power menu and the status area for notifications. Settings can customize the top bar, and Command Line can use your chosen system shell.
- **Reset and performance.** Restore default settings or clear TundraUX data from Settings. The CLI data reset is `tundra-cli reset`. Large documents, image scrolling, and terminal redraws reuse more of their prepared content.

See the [full changelog](https://github.com/peixuanthomas/TundraUX/blob/v2.1.0/docs/CHANGELOG.md#v210--2026-11-28) for changes since v2.0.1.

## Download and installation

| File | Platform |
| --- | --- |
| `TundraUX-v2.1.0-windows-x64.zip` | Windows x64 |
| `TundraUX-v2.1.0-macos-arm64.tar.gz` | macOS Apple Silicon (ARM64) |
| `TundraUX-v2.1.0-linux-x86_64.tar.gz` | Linux x86_64, built on Ubuntu 24.04 |

Each portable archive has a SHA-256 checksum file. Extract the archive and keep its files together. Run `./tundra-shell` on macOS or Linux, or `./tundra-shell.exe` in PowerShell on Windows. On Linux you can also install the `tux` command from the extracted directory.

```sh
tar -xzf TundraUX-v2.1.0-linux-x86_64.tar.gz
cd tundraux-2.1.0-linux-x86_64
./install-tux.sh
tux
```

The packages include English and Chinese resources and require a terminal of at least 108 columns by 20 rows. The macOS package requires Apple Silicon and is unsigned and unnotarized.
